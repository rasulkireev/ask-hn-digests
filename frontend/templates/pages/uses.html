Stack notes

Tech I use

I run multiple projects at the same time. Simple, reliable tools matter more than novelty.

  • Sentry: error tracking and performance monitoring.
  • Hetzner: cloud infrastructure.
  • Buttondown: newsletter delivery.
  • Django: backend web framework.
  • Django-Q2: task queue and scheduler.
  • CapRover: deployment and server management.
  • GitHub: source control and collaboration.
  • Redis: cache and message broker.
  • PostgreSQL: primary database.
  • OpenRouter: AI model routing for content generation and embeddings.
  • Pydantic AI: typed AI generation and model-provider switching.
  • StimulusJS: focused frontend interactivity.
  • WhiteNoise: static file serving.
  • Logfire: logging.
